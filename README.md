# Recurly Blog Code Examples

Source code for the examples published on the [Recurly Engineering Blog](https://recurly.com/blog/).

Each directory is a self-contained project tied to a specific post. See the README inside each one for setup and run instructions.

## Examples

| Directory | Description |
|---|---|
| [`generative-ui-minimalism`](./generative-ui-minimalism) | Minimal generative UI with Google ADK and React |

## Structure

Every example lives in its own top-level directory and is independently runnable. There are no shared dependencies between examples.
